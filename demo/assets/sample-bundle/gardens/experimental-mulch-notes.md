# Experimental Mulch Notes

Three neighboring beds are testing leaf mold, clean straw, and wood chips. Each bed receives the same watering schedule so surface moisture, weed pressure, and soil temperature can be compared.

These observations are preliminary. Check beneath each mulch layer weekly, record moisture before watering, and note any slug activity or compacted material before changing the trial.
