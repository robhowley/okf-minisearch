# Yard Handoff

## Purpose
A yard handoff transfers responsibility, not just a list of tasks. The outgoing shunter briefs the incoming operator beside the working plan before either person moves a vehicle. Confirm the current track, locomotive, consist, brake status, protection limits, and any vehicles that must not be coupled. State which routes are occupied, which points are clipped or locked, and whether a signal, radio, or crossing fault changes the plan.

## Handoff sequence
Read back the movement order and repeat the next intended move in plain language. Walk to the control board or yard diagram and mark completed, active, and deferred work. The incoming operator checks the radio channel, handbrake count, and visible clearance at the first route. If information is missing, stop the transfer and call the yard controller; never infer that an old note still applies.

## Record
Log the time, names, locomotive number, outstanding hazards, and agreed next move. The outgoing operator remains available until the incoming operator confirms acceptance.
