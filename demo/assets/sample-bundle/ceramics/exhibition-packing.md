# Exhibition Packing

## Plan the Package

Measure the work, choose a rigid box with room for cushioning, and gather clean paper, foam, tape, labels, and a packing list. Photograph the piece before wrapping, including its foot and any existing flaw. Do not use loose packing peanuts or materials that shed dust. For a group shipment, assign each package an ID that matches the inventory and installation plan.

## Wrap and Cushion

Wrap handles, rims, and protrusions separately with soft tissue or paper before adding a larger layer. Surround the object with resilient cushioning on every side, keeping pressure off delicate edges. Place it in the center of the box so it cannot touch the walls. Close the box temporarily and perform a gentle movement test; if the piece shifts, reopen it and add fitted support rather than tighter pressure.

## Label and Handoff

Seal the package with tape that can be removed without contacting the artwork. Mark orientation, fragile handling, sender, recipient, package ID, and unpacking instructions. Keep the inventory, insurance value, and tracking number with the shipment record, not loose inside the box. Photograph the closed package at handoff and obtain a named receiver's confirmation.
