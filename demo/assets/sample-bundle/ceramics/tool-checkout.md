# Tool Checkout

## Before Borrowing

Find the tool in its labeled drawer or rack and inspect it before signing it out. Note missing handles, cracked ribs, bent wires, loose blades, and dried clay. Record the tool ID, your name, checkout time, and expected return when the studio uses a paper or digital register. Ask before taking specialty tools reserved for classes, repairs, or exhibition work.

## During Use

Use each tool for its intended material and keep it on a tray when moving between stations. Do not leave sharp needles, fettling knives, or cutting wires hidden under clay. Rinse tools at the designated sink or wipe them with a damp cloth, keeping plaster and glaze solids out of drains. If a tool breaks, stop using it and save the pieces for the steward.

## Return and Repair

Remove all clay, dry the tool, and return it to its marked location before ending the session. Sign it back in with the actual return time. Tag damaged equipment with a short description instead of placing it back in circulation. Report a missing item promptly; a clear record is more useful than replacing a tool twice.
